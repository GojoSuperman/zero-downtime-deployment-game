# 8강. 로드밸런서로 무중단 배포 구성하기 — 인터랙티브 학습 게임

> **모두의연구소** 수업 자료 | 브라우저에서 바로 플레이

## 🎮 플레이

**👉 [게임 바로가기](https://gojosuperman.github.io/zero-downtime-deployment-game/)**

## 📋 소개

로드밸런서와 무중단 배포의 핵심 개념을 **게임으로 배우는** 인터랙티브 학습 자료입니다.

## 🧩 문제게임 (7 스테이지)

| 스테이지 | 주제 | 유형 |
|----------|------|------|
| 1 | 병원 비유로 이해하는 고가용성 | OX 퀴즈 |
| 2 | 가용성과 나인(9) 계산 | 객관식 |
| 3 | 배포 방식 매칭 (롤링·블루그린·카나리) | 매칭 |
| 4 | Nginx 설정 코드 조립 | 코드 조립 |
| 5 | 블루그린 전환 시뮬레이션 | 시뮬레이터 |
| 6 | 장애 실험 & 복구 | 시뮬레이터 |
| 7 | Nginx reload의 원리 | 객관식 |

## 🔫 슈팅게임 (3 스테이지)

| 스테이지 | 주제 | 조작 |
|----------|------|------|
| Stage 1: 로드밸런서 디펜스 | 요청 패킷을 올바른 서버로 라우팅 | 마우스 이동 + 클릭(방향 전환) |
| Stage 2: 패킷 슈터 | 장애 상황을 맞는 해결책으로 격파 | 마우스 이동 + 클릭(발사), 숫자키(무기 선택) |
| Stage 3: 블루그린 스나이퍼 | Nginx 설정 코드를 조준해서 선택 | 클릭(정답 선택) |

## 🛠 기술 스택

- 순수 HTML + CSS + JavaScript (프레임워크 없음)
- Canvas 기반 게임 렌더링
- Web Audio API 효과음/배경음
- localStorage 진행 저장

## 📁 파일 구조

```
index.html    ← 메인 (문제게임 + 정리노트 + 슈팅게임 진입)
shooter.html  ← 슈팅게임 (iframe으로 로드)
```

## 🔄 초기화

게임 하단의 **"처음부터 다시"** 링크를 클릭하면 문제게임 + 슈팅게임 진행이 모두 초기화됩니다.
